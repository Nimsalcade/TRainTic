# Game models

Board packs you can import into the 3-2-5 tactics board.

## Draw. Break. Attack. (2024-25)

`draw-break-attack-2024-25.json` holds 15 animated boards built from the *Draw / Break / Attack* game-model blueprint. They follow the blueprint page by page:

| Board | Blueprint page |
| --- | --- |
| 01 Identity: Draw. Break. Attack. | 1 · Identity |
| 02 Eleven connected roles | 2 · Responsibilities |
| 03 First phase: Invite, then escape | 3 · First phase |
| 04 Middle third A: Receive, turn, release | 4 · Middle third |
| 05 Middle third B: Set, then find the run | 4 · Middle third |
| 06 Flanks: different sides, shared purpose | 5 · Flanks and finishing |
| 07 Transitions: attack with cover | 6 · Protection and transitions |
| 08 Defending: close the centre together | 7 · Defending |
| 09 Choose the height A: higher press | 8 · Defensive variations |
| 10 Choose the height B: deeper 5-4-1 | 8 · Defensive variations |
| 11 Change jobs, keep connections | 9 · Attacking variations |
| 12–14 Practices 1–3 | 10 · Training design |
| 15 The player card: shared calls | 11 · Matchday and review |

Every board has captions on the pitch for each slide, and the blueprint's tables and coaching points in its session notes (Board menu → Session details). Exported images include the notes.

### Import

1. Open the app and go to **Board menu → Import boards**, or **Sessions → Import**.
2. Choose `draw-break-attack-2024-25.json`.
3. All 15 boards appear in **Sessions**, in order, and the first one opens. Nothing you already have is replaced.

On a computer you can also drop the file onto the board.

### Present

Open a board and press play. Drawings draw themselves in, then the players move. Use **Pitch and view → Board view → Stadium** for the floodlit look, and **Export slides** for images or a video to share with the squad.

The diagrams are teaching frames, not tracked match coordinates. Positions show relationships.
